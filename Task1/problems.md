# Проблемные зоны (As-Is)

## 1. Запись пациента
- Передача персональных данных по телефону без шифрования.
- Использование файлов Excel на SMB-шарах (отсутствие шифрования и контроля доступа).
- Нет единого хранилища данных — дублирование записей.
- Уведомления пациентам через почту без TLS/подписей.

## 2. Учёт анализов
- Передача направлений и результатов анализов по почте (PDF/JPG) без гарантированной защиты.
- Хранение результатов на файловом сервере без шифрования.
- Нет централизованного контроля доступа (RBAC/ABAC).
- Отсутствует аудит действий сотрудников.

## 3. Оплата услуг
- Частичная несоответствие требованиям PCI DSS.
- Дублирование учёта между ККМ, 1С и файлами.
- Отсутствие шифрования при хранении транзакций.
- Нет антифрод-контроля.

## 4. Учёт ТМЦ
- Сканы накладных и Excel-файлы хранятся на файловом сервере без шифрования.
- Нет проверки целостности документов (ЭЦП).
- Нет централизованного мониторинга складских операций.
- Слабый контроль прав доступа сотрудников склада.

---

## Общие проблемные зоны
- Отсутствие принципов Privacy by Design.
- Нет систематического подхода к **Data Lineage** (невозможно отследить путь данных).
- Нет механизма управления согласиями пациентов.
- Нет единого журнала аудита событий.
